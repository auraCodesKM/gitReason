Privacy Policy

Last updated: August 20, 2026

This is a course project. GitReason is a student learning project built for a class assignment, not a commercial product or a company. It is provided for demonstration and educational purposes only — please be cautious about how much you rely on it, and treat anything you enter here as if it isn't private.

What data this site collects

GitReason's own code does not collect, store, or transmit any personal data. There is no account system, no database, and no analytics script on this site. The "Analyze a Repository" field never leaves your browser — submitting it only opens the GitHub page for the repository name you typed, in a new tab, using your browser's normal link-opening behavior.

Third-party resources

This page loads fonts from Google Fonts. Loading a font from Google's servers means your browser makes a request to Google, which can see your IP address the same way any web request would, under Google's own font privacy practices. No other third-party service is embedded in this site.

Cookies

This site does not set cookies of its own.

Changes

This policy may change as the course project develops. Since there's no account system, there's no way to notify you directly — check back here if you're curious.

Contact

This is a learning project with no company or support channel behind it. There is no data to request, correct, or delete, because none is collected.
